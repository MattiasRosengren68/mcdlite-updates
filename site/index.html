Open an experiment

  1. Open a workspace file (.mcdws) from the Workspace menu.
  2. In the workspace tree, double-click an experiment to start it.
  3. If it is already running, choose whether to restart it. No is the default.
EPK mismatch: using an A2L that does not match the ECU software can address the wrong signals and corrupt measurements or calibration. Ignore only when you have confirmed the difference is harmless.

Find and assign signals

  1. Open Signal Assignment from the toolbar or press Insert.
  2. Type a signal name. Search starts after a short pause; press Enter to search immediately.
  3. Use * for any number of characters and ? for one character. With no wildcard, partial matches are included automatically.
  4. Select a result, choose its DAQ list, then Apply.

Search displays at most 500 results. Refine the name or wildcard pattern if the result limit is reached.

Display values

Right-click a numeric measurement and choose Display Style to switch between Numeric, Bar, Dial, and Arc. Use Display Range to set its minimum, maximum, and warning threshold.

When a value passes its warning threshold, the active warning indication flashes. The threshold itself remains marked on Bar and Arc views.

Record data

Press F8 to start recording. Press F9 to stop and enter the recording details.
